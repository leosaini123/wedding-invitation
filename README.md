# Lovepreet & Arohi — Wedding Invitation

A single-page wedding invitation website (plain HTML / CSS / JS).
**23 & 24 November 2026 · Amritsar, Punjab.**

Open `index.html` in any browser, or view the deployed site on GitHub Pages.

## Structure
- `index.html` — page markup
- `styles.css` — styling
- `script.js` — reveals, countdown, lightbox
- `photos/` — event & portrait images

## Photos
Each event ships with a hand-drawn illustration (`photos/<name>.svg`). To use a real
photo, drop `photos/<name>.webp` (names: `haldi`, `jaggo`, `sangeet`, `barat`,
`varmala`, `pooja`) into the folder — it replaces the illustration automatically.
See `photos/PHOTO-LINKS.md` for free image sources.
