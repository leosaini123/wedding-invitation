# Photos to add later

The site shows my hand-drawn illustration for each spot **until** you drop a real photo here.
To replace one: download an image, **rename it to the exact filename** below, and put it in this
`photos/` folder. `.webp` is preferred; `.jpg` / `.png` also work (if you use a different
extension, tell me and I'll point the code at it).

All links below are **free-to-use stock** (Pexels / Unsplash / Pixabay — no attribution required).
Always glance at the licence line on each page before downloading.
